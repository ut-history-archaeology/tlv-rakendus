Ehitame Next.js rakendust Tartu Linnavolikogu 1917–1941 andmestikule.  
Lähteülesanne: CLAUDE_CODE_ULESANNE.md (1. etapp, loe esimesena) ja CLAUDE_CODE_ULESANNE_2.md (2. etapp: protokollide leht, loe enne protokollidega töötamist).  
Andmesõnastik: data/README.md (loe enne andmetega töötamist).  
Protokollikorpus: korpus/json/ (toor-EstNLTK, ei lähe väljundisse); eeltöötlus `npm run eeltootle` → public/protokollid/ (gitignore); lehepildid public/pildid/ (gitis).  
Kasutajaliidese keel on eesti keel.  
Andmevastuolusid ei lahendata koodis heuristikaga — need kirjutatakse README.md jaotisse "Lahtised andmeküsimused".
